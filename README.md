# AI English Learning

这是一个用于验证“语境式英语学习”的浏览器插件 MVP。

它会在网页正文中进行少量双向替换：

- 中文网页：把部分中文词或词组替换成英文表达
- 英文网页：把部分英文词或词组替换成中文解释
- 鼠标悬停：显示原文、解释、例句，并支持收藏或忽略

插件不依赖构建工具，可以直接加载 `extension` 目录运行。默认使用内置词表；在设置页配置 OpenAI 兼容接口后，可以启用 AI 替换建议、中文改写和复习反馈。

## 本地安装

1. 打开 Chrome 或 Edge
2. 进入扩展管理页
   - Chrome：`chrome://extensions`
   - Edge：`edge://extensions`
3. 开启“开发者模式”
4. 点击“加载已解压的扩展程序”
5. 选择本项目中的 `extension` 目录

## 使用方式

- 打开任意中文或英文网页
- 页面正文中会出现少量带下划线的替换词
- 鼠标悬停在替换词上，可以看到原文、解释和例句
- 点击插件图标，可以开启/关闭替换、调整替换方向和强度
- 点击插件图标里的“打开生词本”“开始复习”“中文改写”进入完整学习页
- 在网页中划选一个词或词组，可以点击“添加到词库”，手动填写中英文、解释和例句

## 当前功能

- 浏览器 DOM 文本替换
- 中文到英文、英文到中文双向替换
- hover 浮层
- hover 浮层和词卡音标展示，缺失音标会自动查询并缓存
- 收藏词条
- 忽略词条
- 当前页面恢复原文
- 当前网站暂停/启用
- 插件弹窗设置
- 生词本管理
- 划词添加个人词库
- 可关闭内置少量词库，只使用个人词库替换
- 可对单个词取消替换，并在设置里恢复
- 掌握状态：陌生、被动认识、半熟、主动可用、已掌握
- 每日复习任务
- 中文改写成自然英文
- 可选 AI 替换建议
- 可选 AI 复习反馈
- 数据导出
- 本地学习数据清空

## AI 设置

进入插件弹窗，点击“设置”，填写：

- API Endpoint：默认 `https://api.openai.com/v1/chat/completions`
- Model：默认 `gpt-4o-mini`
- API Key：你的接口密钥
- 勾选“启用 AI 替换、改写和复习反馈”

API key 只保存在浏览器本地存储里。开启 AI 后，插件会把有限的页面正文片段发送到你配置的接口，用于生成替换建议。

划词添加时也可以使用“AI 补全”，让 AI 生成中文含义、英文表达、音标、解释和例句。没有配置 AI 时，仍然可以手动填写并保存。

当前只有在这些动作里才会真的调用 API：

- 网页 AI 候选替换
- 中文改写
- 复习反馈
- 划词后的 AI 补全

设置页里提供了“测试 API 是否通畅”按钮，会直接用当前输入发起一次轻量请求，不需要先保存。

## 音标策略

内置精选表达包含手写音标；CET-4 核心词和个人词库如果缺少音标，插件会在 hover 或打开生词本时查询一次公开词典接口，并把结果缓存在浏览器本地。短语和不规则文本会跳过自动查询，仍然可以手动填写或用 AI 补全。

## 词库策略

默认替换来源包括：

- 个人词库：你 hover 收藏或划词添加的词，优先级最高
- 内置少量词库：12 个精选表达 + 273 个 CET-4 常用核心词
- AI 临时候选：开启 AI 后，当前页面中临时推荐的表达

如果在设置里关闭“使用内置少量替换词库”，网页自动替换只使用个人词库。这样适合只想复习自己主动添加过的词，不让系统额外推荐内容。

当前内置词库文件很轻量，CET-4 核心词库约 16KB。替换时仍受强度限制，默认每页最多 5 个，避免把页面变成密集的中英混排。

## 当前不包含

- 桌面全局快捷键划词解释
- OCR 识别图片、视频字幕或桌面软件文字
- 云同步和账号系统
- 浏览器商店打包发布

这些能力需要桌面应用或服务端能力，后续可以在插件核心体验稳定后继续开发。

当前项目没有构建步骤。修改后可以运行：

```powershell
node --check .\extension\src\dictionary.js
node --check .\extension\src\content.js
node --check .\extension\src\popup.js
node --check .\extension\src\app.js
node --check .\extension\src\background.js
Get-Content -Raw .\extension\manifest.json | ConvertFrom-Json | Out-Null
```
